# Raw geography (not committed: large)

Run `python scripts/fetch_geo.py` to download into this folder:

- `bycode2023.xlsx` — CBS locality file (data.gov.il, dataset `localities-in-israel`)
- `sa2020.gdb.zip` → `sa2020/` — CBS statistical areas 2011 with 2020 data (cbs.gov.il geo-layers)
- `muni_il.geojson` — municipal jurisdictions, GovMap open-data WFS layer `opendata:muni_il`

GovMap neighborhood results (`data/raw/govmap/`) are small and committed.
